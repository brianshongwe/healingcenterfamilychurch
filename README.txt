Sanctuary — Church & Ministry Website Template

Sanctuary is a warm, reverent website template for churches, ministries, and faith
communities, with a home page and a filterable sermon library. It is free for both
personal and commercial use, built on self-hosted Bootstrap 5 with a Fraunces +
Figtree type pairing, and powered entirely by vanilla JavaScript — no jQuery and no
build step. Just open index.html in your browser, replace the placeholder images in
the img folder with your own, edit the text, and publish.
